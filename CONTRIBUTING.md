# Contributing

Thanks for helping improve AI Pulse!

## Before submitting

1. Keep secrets, bot tokens, chat IDs and personal data out of commits.
2. Test workflow changes in a non-production n8n workflow first.
3. Update the README when setup steps or behavior changes.
4. Keep changes focused and explain why they are useful.

## Pull requests

Include:
- A short description of the change.
- n8n version tested, if relevant.
- Test steps and observed results.
- Screenshots only when they do not expose credentials or personal data.
